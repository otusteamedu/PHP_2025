### Бэк - Сервис А

Проверка ожидаемых ответов (предположительные ответы, т.к. сервис в теории может вернуть все что угодно?)

```
    Если неверный URI у URL,
    то сервис возвращает ошибку 404
```
```
    Если входные данные пусты или их недостаточно,
    то сервис возвращает ошибку 400
```
```
    Если входные данные не консистенты,
    то сервис возвращает ошибку 403
```
```
    Если входные данные консистенты,
    то сервис возвращает статус 200
```

### Бэк - Репозиторий

Проверка работы с БД

```
    Если данные не консистентны,
    то setOrderIsPaid возвращает false
```
```
    Если данные консистентны, но списание не успешно,
    то setOrderIsPaid возвращает false
```
```
    Если данные консистентны и списание успешно,
    то setOrderIsPaid возвращает true
```

Проверка работы исключений - исключения появляются тогда, когда их ожидают и не появляются тогда, когда их не ожидают
