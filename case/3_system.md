# Системные тесты

1. Отправка формы
```
    Если отправка формы была с невалидными данными,
    то невалидные поля подсвечиваются
```
```
    Если отправка формы была с валидными, но не консистентными данными,
    то выводится сообщение об ошибке "Не удалось списать данные с карты, проверьте реквизиты"
```
```
    Если отправка формы была с валидными данными,
    то отправляется сообщение об успешном списании денег и фильм открывается для просмотра
```
