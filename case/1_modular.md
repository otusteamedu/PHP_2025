# Модульные тесты

## Проверка запроса

- негативные тесты

  ```
  Если это не POST-запрос,
  то выводится сообщение об ошибке с кодом 400
  ```

  ```
  Если входный данных нет ($_POST или php://input),
  то выводится сообщение об ошибке с кодом 400
  ```

  ```
  Если входные данные не десериализуются в валидный объект,
  то выводится сообщение об ошибке с кодом 400
  ```

## Валидация входных параметров

### 1. card_number

- Негативные тесты:

  ```
      Если параметра нет или он пустой,
      то выводится сообщение об ошибке с кодом 400
  ```

  ```
      Если тип параметра не "строка",
      то выводится сообщение об ошибке с кодом 400
  ```

  ```
      Если длина параметра не равна 16,
      то выводится сообщение об ошибке с кодом 400
  ```

  ```
      Если в параметре есть любой символ кроме цифр,
      то выводится сообщение об ошибке с кодом 400
  ```

- Позитивные тесты:

  ```
      Если параметр:
      - существует;
      - он не пустой;
      - тип параметра "строка";
      - длина параметра равна 16;
      - есть только символы цифр;
      то параметр считается валидным
  ```

- Примеры невалидного card_number:

  ```php
  $card_number = null;
  $card_number = "";
  $card_number = "123";
  $card_number = "1111111111111111111111111";
  $card_number = "132asdlk12312313";
  $card_number = "1234 1234 1234 1234";
  ```

- Примеры валидного card_number:
  ```php
  $card_number = "1234123412341234";
  $card_number = "7438012659127342";
  $card_number = "0350123871202132";
  ```

### 2. card_holder

- Негативные тесты:

  ```
      Если параметра нет или он пустой,
      то выводится сообщение об ошибке с кодом 400
  ```

  ```
      Если тип параметра не "строка",
      то выводится сообщение об ошибке с кодом 400
  ```

  ```
      Если длина параметра меньше 5 символов,         //2 на имя и 2 на фамилию + пробел
      то выводится сообщение об ошибке с кодом 400
  ```

  ```
      Если в параметре нет пробелов или их больше 1,
      то выводится сообщение об ошибке с кодом 400
  ```

  ```
      Если длина параметра больше ~200 символов (или больше ограничения длины параметра в БД)
      то выводится сообщение об ошибке с кодом 400
  ```

  ```
      Если в параметре есть любой символ кроме латиницы и одного пробела,
      то выводится сообщение об ошибке с кодом 400
  ```

  - Позитивные тесты:

  ```
      Если параметр:
      - существует;
      - он не пустой;
      - тип параметра "строка";
      - длина параметра от 5 до 200 включительно;
      - есть только символы латиницы и один обязательный пробел;
      то параметр считается валидным
  ```

  - Примеры невалидного card_holder:

  ```php
  $card_holder = null;
  $card_holder = "";
  $card_holder = "a a";
  $card_holder = "IvanovIvan";
  $card_holder = "Ivanov Ivan Ivanovich";
  $card_holder = "Ivan0v_Ivan";
  ```

- Пример валидного card_holder:
  ```php
  $card_holder = "Ivanov Ivan";
  $card_holder = "LARKINOV BUYANTO";
  $card_holder = "YURI gagarin";
  $card_holder = "la la";
  ```

### 3. card_expiration

- Негативные тесты:

```
      Если параметра нет или он пустой,
      то выводится сообщение об ошибке с кодом 400
```

```
      Если тип параметра не "строка",
      то выводится сообщение об ошибке с кодом 400
```

```
      Если длина параметра не равна 5,
      то выводится сообщение об ошибке с кодом 400
```

```
      Если параметр не соответствует шаблону MM/YY,
      то выводится сообщение об ошибке с кодом 400
```

```
      Если параметр соответствует шаблону MM/YY, но MM принимает некорректное значение,
      то выводится сообщение об ошибке с кодом 400
```

```
      Если в параметре есть любой символ кроме цифр и одной косой черты,
      то выводится сообщение об ошибке с кодом 400
```

- Позитивные тесты:

  ```
      Если параметр:
      - существует;
      - он не пустой;
      - тип параметра "строка";
      - длина параметра равна 5;
      - параметр представляет собой шаблон даты MM/YY;
      - месяц корректен (не больше 12);
      - есть только символы цифр и одна косая черта;
      то параметр считается валидным
  ```

  - Примеры невалидного card_expiration:

  ```php
  $card_expiration = null;
  $card_expiration = "";
  $card_expiration = "01-01";
  $card_expiration = "12/01/25";
  $card_expiration = "13/13";
  ```

- Пример валидного card_expiration:
  ```php
  $card_expiration = "01/01";
  $card_expiration = "05/18";
  $card_expiration = "12/28";
  $card_expiration = "05/12";
  ```

### 6. sum

- Негативные тесты:

```
      Если параметра нет или он пустой,
      то выводится сообщение об ошибке с кодом 400
```

```
      Если тип параметра не "строка",
      то выводится сообщение об ошибке с кодом 400
```

```
      Если в параметре есть любой символ кроме цифр и одной обязательной запятой,
      то выводится сообщение об ошибке с кодом 400
```
```
      Если в параметре нет запятой или их больше одной,
      то выводится сообщение об ошибке с кодом 400
```
```
      Если в параметр начинается или заканчивается запятой,
      то выводится сообщение об ошибке с кодом 400
```

- Позитивные тесты:

  ```
      Если параметр:
      - существует;
      - он не пустой;
      - тип параметра "строка";
      - есть только символы цифр и одна запятая;
      - запятая не первый и не последний символ;
      то параметр считается валидным
  ```

  - Примеры невалидного sum:

  ```php
  $sum = null;
  $sum = "";
  $sum = 1;
  $sum = 1.0;
  $sum = 1,0;
  $sum = "1.0";
  $sum = ",5";
  $sum = "10,";
  ```

- Пример валидного sum:
  ```php
  $sum = "0,0";
  $sum = "000000,0";
  $sum = "123,01";
  $sum = "23423431,23";
  $sum = "323,5";
  ```
