## 2. Интеграционное тесты
### Проверяем связку «фронт-бэк»:
   1. Фронт отправил на бэк пустой json, в ответ получаем ошибку: "Нет данных для проведения операции". 
   2. Фронт отправил на бэк Не валидное поле card_number, в ответ получаем ошибку; 
   3. Фронт отправил на бэк Не валидное поле card_holder, в ответ получаем ошибку;
   4. Фронт отправил на бэк Не валидное поле cvv, в ответ получаем ошибку;
   5. Фронт отправил на бэк Не валидное поле order_number, в ответ получаем ошибку; 
   6. Фронт отправил на бэк Не валидное поле sum, в ответ получаем ошибку;
   7. Фронт получает ответ со статусом 403, то в ответ получаем ошибку;
   8. Фронт не получает ответ бэк, то в ответ получаем ошибку;

### Проверяем связку «бэк-сервис A»:
   1. Бэк получает ошибку от сервиса и возвращает ошибку 403;
   2. Бэк не получил ответ от сервиса и возвращает ошибку 403; 
   3. Бэк получил ответ от сервиса и возвращает 200;

### Проверяем связку «бэк-репозиторий»:
1. Бэк вызывает метод setOrderIsPaid репозитория, если приходит Exception возвращает ошибку 400 и текст ошибки;
2. Бэк вызывает метод setOrderIsPaid репозитория, если приходит true, то возвращает 200;

## 3. Системные тесты
   В проверке участвуют все поля:
   * card_number;
   * card_holder;
   * card_expiration;
   * cvv;
   * order_number;
   * sum.

1. Проверка полей на пустоту. 
    При попытке оплатить фильм поля, которое не заполнены, должны иметь красный outline, 
    над формой выводится строка с ошибкой, в которой перечислены пустые поля.
    Текст ошибки: "Не заполнено(ы) поле(я) формы: "Названия поля(ей) формы"". Если ошибка касается нескольких полей, то они должны быть перечислены через ",".
2.  Проверка полей на валидность.
       При попытке оплатить фильм невалидные поля, должны иметь красный outline,
       над формой выводится список ошибок, в котором перечислены невалидные поля.
    Требования к сообщению об ошибке:
       * В каждой строке списка находится текст ошибки;
       * Для каждого поля может быть только одно сообщение об ошибке;
       * В ошибке обязательно должно присутствовать название поля из формы.
       
    Пример текста об ошибки: "В поле cvv недостаточно цифр". 
3. Введенные данные валидны.
   1. Пользователь нажал на кнопку оплатить. При успешном списании средств пользователь видит попап с текстом: "Оплата прошла успешна, спасибо за покупку!";
   2. Пользователь нажал на кнопку оплатить. Если не удалось списать средства, пользователь видит попап с текстом: "Оплата не прошла. #текст сообщения из Exception, полученного с бэкенда";
   3. Если не удается получить ответ от бэкенда, пользователь видит попап с текстом: "К сожалению, сервис сейчас недоступен. Приносим свои извинения. Для получения подробной информации вы можете обратиться по номеру #Номер телефона техподдержки#"
