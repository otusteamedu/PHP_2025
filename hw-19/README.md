# Инструкция по запуску проекта

### 1. Клонирование репозитория

Сначала клонируйте репозиторий

```bash
git clone <URL_репозитория>
````

### 2. Создайте .env

В директории app создайте .env клонировав .env.template

### 3. Сборка Docker контейнеров

Для сборки Docker контейнеров выполните следующую команду:

```bash
make start
```

### 4. Запуск консюмера

Для запуска консюмера, который будет обрабатывать сообщения, выполните команду:

```bash
make start-consumer
```

### 5. Выполнение команды для получения банковской выписки

Откройте новое окно терминала и выполните команду для активации терминала:

```bash
make terminal
```

В открывшемся терминале выполните команду для получения банковской выписки, указав необходимые параметры:

```bash
php public/index.php get-bank-statement <account> <dateFrom> <dateTo>
```

Пример:

```bash
php public/index.php get-bank-statement 40817810099910001234 2024-01-01 2024-01-31
```

Теперь консюмер будет обрабатывать запросы, и вы получите выписку по заданному счету и периоду.
