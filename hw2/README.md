# PHP_2025

### Консольные приложения на Docker

### Проект содержит два консольных приложения, упакованных в Docker-контейнеры.

### 🚀 Быстрый старт

1. Собрать Docker образы

```
make build
```

2. Запуск контейнера sum-calculator

```
make sum
```
### Примеры
```
make sum ARGS="1.5-3"     # Вычислить сумму: 1.5 + (-3)
make sum ARGS="10+5"      # Вычислить сумму: 10 + 5
make sum ARGS="2.5-1.5"   # Вычислить сумму: 2.5 + (-1.5)
```
3. Запуск контейнера city-analyzer

```
make cities
```
