# PHP_2025

Домашняя работа по уроку номер 13  
Консольное PHP приложение - поисковик книг через Elasticsearch с поддержкой различных параметров фильтрации.


## Требования

- PHP 7.4 или выше
- Elasticsearch 7.x или выше
- Composer

## Использование


Для вывода результата используйте команду `php search.php -q 'лыцари'`.


Доступно 4 ключа : n,c,p,u


 **`-n`**  **Название** - поиск по названию книги.Строка\
 Обязательный. Доступна одна орфографическая ошибка.\
 `-n 'рыцори'` 

 **`-c`**  **Категория** - фильтр по категории книги  Строка.\
 Строгое соответсвие.\
 `-c 'любовные романы'`

 **`-p`**  **Цена** - максимальная цена книги. Число.\
 По умолчанию 2000.\
`-p 2500` 


 **`-u`**  **Недоступность** - показывать отсутствующие книги.\
 При наличии в запросе выведет так же книги которых нет на складе\
 `-u`
