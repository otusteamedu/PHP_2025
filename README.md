# HW10

Консольное приложение для поиска книг в ElasticSearch

Консольные команды:
1. Создаёт индекс и загружает данные из JSON файла
```bash
php bin/console shop:index:build --file=otus-shop.json
```
| Параметр | Описание                |
|----------|-------------------------|
| --file   | Путь до файла с данными |
2. Выполняет поиск книг по заданным параметрам (как по всем, так и по отдельным), также учтён поиск с ошибками (рыцОри - рыцари)
```bash
php bin/console shop:search --title="рыцари" --category="исторический роман" --max-price=2000 --in-stock
```
| Параметр | Описание                              |
|--------|---------------------------------------|
| --title | Название книги                        |
| --category | Категория                             |
| --max-price | Максимальная цена                     |
| --in-stock | bool флаг для вывода книг - в наличии |
