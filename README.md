# Условия

- `card_number` — номер карты, 16 цифр
- `card_holder` — имя и фамилия латиницей, допускается дефис
- `card_expiration` — срок действия карты в формате `dd/yy`
- `cvv` — 3 цифры
- `order_number` — номер заказа, до 16 символов
- `sum` — сумма оплаты, строка с запятой как разделитель дробной части

Бэк выполняет:

1. Валидацию данных (ошибка - `400`)
2. Запрос в сервис **A**
    - `403` — списание не удалось
    - `200` — списание успешно
3. При успехе — `setOrderIsPaid()`

---

# Возможные ошибки

- **400 (валидация)**
    - соответствующее поле подсвечивается красной рамкой
    - под формой выводится текст ошибки
- **403 (ошибка списания)**
    - сообщение:  
      **«Не удалось списать средства, проверьте реквизиты карты»**
- **200 (успех)**
    - переход на страницу «Оплата прошла успешно»

## Валидация

### card_number

- Не [0-9]{16} - `400`
- Отсутствует - `400`

### card_holder

- Более одного пробела - `400`
- Не латиница - `400`
- Содержит цифры - `400`
- Содержит два дефиса подряд - `400`
- Пустое значение - `400`

### card_expiration

- Формат не `dd/yy` - `400`
- Месяц < 01 или > 12 - `400`
- Срок действия в прошлом - `400`
- Отсутствует - `400`

### cvv

- Не [0-9]{3} - `400`
- Отсутствует - `400`

### order_number

- Длина > 16 - `400`
- Пустое значение - `400`

### sum

- Не строка - `400`
- Нет запятой - `400`
- Содержит буквы - `400`
- Значение <= 0 - `400`

---

## Корректных данные

- Сервис A вернул `403` - контроллер возвращает `403`
- Сервис A вернул `200`, репозиторий выбросил исключение - `500`
- Сервис A вернул `200`, репозиторий вернул `true` - `200`
