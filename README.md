# REST API с использованием очередей

Этот проект реализует REST API, которое позволяет пользователям отправлять запросы на обработку, помещать их в очередь и проверять статус обработки по уникальному идентификатору.

## Функциональность

- **Запрос на обработку**: Клиенты могут отправить POST-запрос с параметрами (например, диапазон дат) для создания задачи на обработку. API возвращает уникальный идентификатор задачи (job ID).
- **Проверка статуса**: Клиенты могут использовать полученный job ID для проверки текущего статуса задачи (например, `new`, `active`, `completed`).
- **Обработка в фоне**: Отдельный консольный процесс (consumer) извлекает задачи из очереди и обрабатывает их асинхронно.
- **Получение результата**: После завершения обработки задачи, связанный с ней результат (например, банковская выписка) становится доступен по отдельному URL, который возвращается при проверке статуса.

## Установка

Создать .env файл и заполнить все переменные. Они будут использоваться при создании контенеров и для подключения.

Запустить контейнеры командой
```
docker compose up --build
```
Все основные зависимости (установка composer зависимостей, инициализация БД) установятся во время инициализации контейнера.
Consumer также будет запущен вместе с контейнерами
