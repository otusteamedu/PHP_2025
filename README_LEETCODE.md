# Решения задач LeetCode на PHP

Реализация четырех задач LeetCode с оптимальной сложностью, обработкой граничных случаев и тестами.

## Решенные задачи

### 1. Intersection of Two Arrays
**Ссылка:** https://leetcode.com/problems/intersection-of-two-arrays/

**Задача:** Найти пересечение двух массивов (общие уникальные элементы).

**Решение:**
- Используем HashSet для первого массива
- Проходим по второму массиву и проверяем наличие в множестве
- Используем дополнительное множество для результата (уникальность)

**Сложность:**
- **Время:** O(n + m), где n = |nums1|, m = |nums2|
- **Память:** O(min(n, m))

**Граничные случаи:**
- Пустые массивы
- Отсутствие пересечений
- Дубликаты в массивах

---

### 2. Largest Positive Integer That Exists With Its Negative
**Ссылка:** https://leetcode.com/problems/largest-positive-integer-that-exists-with-its-negative/

**Задача:** Найти наибольшее положительное число k, для которого -k также существует в массиве.

**Решение:**
- Создаем HashSet из всех чисел
- Проходим по массиву, ищем положительные числа
- Для каждого положительного проверяем наличие его отрицания
- Отслеживаем максимум

**Сложность:**
- **Время:** O(n)
- **Память:** O(n)

**Граничные случаи:**
- Пустой массив → возврат -1
- Нет пары → возврат -1
- Только положительные или только отрицательные числа

---

### 3. Two Sum
**Ссылка:** https://leetcode.com/problems/two-sum/

**Задача:** Найти два числа, сумма которых равна target. Вернуть их индексы.

**Решение (One-pass Hash Table):**
- Проходим по массиву один раз
- Для каждого элемента вычисляем complement = target - nums[i]
- Проверяем наличие complement в хеш-таблице
- Если есть - возвращаем индексы, если нет - добавляем текущий элемент

**Сложность:**
- **Время:** O(n)
- **Память:** O(n)

**Граничные случаи:**
- Массив содержит менее 2 элементов
- Отрицательные числа
- Одинаковые числа (нельзя использовать один элемент дважды)

**Альтернатива (Brute Force):**
- Время: O(n²)
- Память: O(1)

### 4. Sort Array by Increasing Frequency
**Ссылка:** https://leetcode.com/problems/sort-array-by-increasing-frequency/

**Задача:** Отсортировать массив по частоте (по возрастанию). При одинаковой частоте - по значению (по убыванию).

**Решение:**
- Подсчитываем частоту каждого элемента
- Сортируем массив с кастомным компаратором:
  - Сначала по частоте (возрастание)
  - При равной частоте - по значению (убывание)

**Сложность:**
- **Время:** O(n log n)
- **Память:** O(n)

**Граничные случаи:**
- Пустой массив
- Один элемент
- Все элементы уникальны
- Все элементы одинаковые
