# Bracket Validator & Load Balancer (HW4)

Данный проект реализует сервис верификации скобочных последовательностей на базе фреймворка **Laravel**, работающий в отказоустойчивой среде с балансировщиком нагрузки.

## Архитектура проекта

*   **Balancer (Nginx)**: Принимает внешний трафик на порту 80 и распределяет его между узлами.
*   **Nginx-1 & Nginx-2**: Веб-серверы, обрабатывающие статику и проксирующие PHP-запросы через Unix-сокеты.
*   **PHP-FPM Nodes**: Два независимых инстанса PHP 8.2, исполняющих код приложения.
*   **Core Namespace**: Бизнес-логика вынесена в отдельную директорию `Core` для чистоты архитектуры.

## Требования

*   Docker / Docker Compose
*   PHP 8.2+ (локально для установки зависимостей)

## Инструкция по запуску

### 1. Подготовка исходного кода
Перейдите в директорию с исходным кодом Laravel и установите зависимости:

```bash
cd app/src
composer install
```
 
### 2. Настройте права доступа

```bash
chmod -R 777 storage bootstrap/cache
```
### 3. Обновите автозагрузку классов:

```bash
composer dump-autoload
```

### 4. Запуск инфраструктуры

```bash
docker-compose up -d --build
```

## После старта будут доступны следующие адреса:
* http://localhost — Балансировщик (основная точка входа).
* http://localhost:8081 — Прямой доступ к Nginx-1.
* http://localhost:8082 — Прямой доступ к Nginx-2.


### 5. Тестирование
## 4.1. Проверка балансировки (UI)
Откройте браузер и перейдите на http://localhost.
Вы увидите приветственную страницу "Hello from docker container".
В строке container_id отобразится ID текущего контейнера.
Обновите страницу несколько раз (или откройте в режиме инкогнито) — ID должен меняться, что подтверждает работу балансировщика.
## 4.2. Верификация скобок (POST API)
Сервис ожидает POST запрос с параметром string. Валидация исключена из проверки CSRF в bootstrap/app.php для удобства тестирования.
Сценарий: Корректная строка (Ответ 200 OK)

```bash
curl -i -X POST http://localhost/ -d "string=(()())"
```

Ожидаемый ответ: Всё хорошо
Сценарий: Некорректная строка (Ответ 400 Bad Request)
```bash
curl -i -X POST http://localhost/ -d "string=(()))"
```

Ожидаемый ответ: Всё плохо
Сценарий: Пустая строка (Ответ 400 Bad Request)
```bash
curl -i -X POST http://localhost/ -d "string="
```
