# Решение задачи: Merge Two Sorted Lists

## Описание задачи

Объединить два отсортированных связанных списка в один отсортированный список. Результат должен быть объединением узлов из двух заданных списков.

**Пример:**
- Вход: `list1 = [1,2,4]`, `list2 = [1,3,4]`
- Выход: `[1,1,2,3,4,4]`

## Решение

### Алгоритм

Используется итеративный подход с двумя указателями:

1. **Создание фиктивного узла (dummy node)**: Упрощает логику, избавляя от проверки пустого результата при первом добавлении
2. **Сравнение элементов**: На каждой итерации сравниваем значения текущих узлов из обоих списков
3. **Добавление меньшего элемента**: Меньший узел добавляется к результату, указатель соответствующего списка перемещается вперед
4. **Присоединение остатка**: После завершения одного из списков, оставшиеся узлы другого списка присоединяются к результату

### Код решения

```php
public function mergeTwoLists(?ListNode $list1, ?ListNode $list2): ?ListNode
{
    $dummy = new ListNode();
    $current = $dummy;
    
    while ($list1 !== null && $list2 !== null) {
        if ($list1->val <= $list2->val) {
            $current->next = $list1;
            $list1 = $list1->next;
        } else {
            $current->next = $list2;
            $list2 = $list2->next;
        }
        $current = $current->next;
    }
    
    $current->next = $list1 !== null ? $list1 : $list2;
    
    return $dummy->next;
}
```

## Анализ сложности

### Временная сложность: **O(m + n)**

Где:
- `m` - длина первого списка
- `n` - длина второго списка

**Обоснование:**
- Каждый узел из обоих списков посещается ровно один раз
- В цикле `while` выполняется не более `m + n` итераций
- Все операции внутри цикла выполняются за O(1)

### Пространственная сложность: **O(1)**

**Обоснование:**
- Используется только фиксированное количество дополнительных переменных:
  - `$dummy` - фиктивный узел
  - `$current` - указатель на текущий узел результата
- Не создаются новые узлы, только перестраиваются связи существующих
- Не используется рекурсия (которая потребовала бы O(m + n) для стека вызовов)

**Примечание:** Если считать пространство, занимаемое результирующим списком, то пространственная сложность будет O(m + n), но это выходные данные, которые необходимы по условию задачи. Дополнительная память (без учета результата) - O(1).

## Обработка исключительных случаев

Решение корректно обрабатывает все граничные случаи:

1. **Оба списка пусты** (`null`)
   - Возвращается `null`
   - Обрабатывается автоматически: `$dummy->next` будет `null`

2. **Один из списков пуст**
   - Возвращается другой список целиком
   - Обрабатывается строкой: `$current->next = $list1 !== null ? $list1 : $list2;`

3. **Списки с одним элементом**
   - Корректно сравниваются и объединяются

4. **Списки разной длины**
   - После завершения короткого списка, остаток длинного автоматически присоединяется

5. **Дублирующиеся значения**
   - При равенстве значений (`$list1->val <= $list2->val`) выбирается элемент из первого списка, что обеспечивает стабильность сортировки

6. **Отрицательные числа**
   - Сравнение работает корректно для любых целых чисел в диапазоне [-100, 100]

## Оптимальность решения

Данное решение является **оптимальным** по следующим причинам:

1. **Временная сложность O(m + n)** - минимально возможная, так как необходимо посетить каждый узел хотя бы один раз
2. **Пространственная сложность O(1)** - не создаются новые узлы, только перестраиваются связи
3. **Итеративный подход** - избегает накладных расходов на рекурсию
4. **Простота реализации** - код легко читается и поддерживается
